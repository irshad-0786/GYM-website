🏋️ IronFit Gym

A modern, responsive gym website built with HTML, CSS, and JavaScript.

✨ Features

- 📱 Fully responsive design
- ☰ Mobile hamburger navigation
- 🎨 Modern dark gym-themed UI
- 🏋️ Gym services section
- 💳 Membership plans
- 📝 Membership registration modal
- 💬 Membership form → WhatsApp
- 📩 Contact form → WhatsApp
- 🎬 Gym video section
- ✨ Scroll reveal animations
- 👨‍🏫 Trainers section
- 🏢 Facilities section
- ⭐ Testimonials section
🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub
